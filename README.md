# BÖRÜ: SON KRAL

> Gökten düşen son ejderhanın fetih destanı. Telefona uygulama gibi kurulur.

**Etiketler:** Tarayıcı Oyunu · PWA · Mobil

## 12'li Arena

Çevrimiçi savaşta yeni mod: haritada 12 ejderha, takım ve dostluk yok. Arkadaşlarınla (oda kodu) ya da tek başına oynayabilirsin; tek başınaysan aktif oyuncularla eşleşilir, yoksa boş yerler savaşçılarla dolar. Herkesin konumu haritada görünür, savaş alanı zamanla daralır, herkes elenince maç biter.

## Çalıştırma

Tek dosyalık bir web projesi — `index.html` dosyasını tarayıcıda açman yeterli. Vercel'de statik site olarak yayınlanır.
